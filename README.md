# A. Music – Listen together on the web

Join an A. Music "Listening together" session from any browser: iPhone, iPad, Mac, Windows, Linux, Android.
Open the page, type the code from the host's phone, tap **Join**. On iPhone: Share → Add to Home Screen.

- Speaks protocol 1 of the app: the code names a private channel and is the key (PBKDF2-SHA256 → AES-256-GCM); nothing but tiny encrypted messages passes through two public relays (ntfy.sh, ntfy.envs.net).
- Plays through YouTube's embedded player, kept in step with the host the same way the app does it.
- This page is a guest. The host is an A. Music phone.

Limits: Safari needs a tap before sound; the embedded player stops when an iPhone screen locks; a few songs can't play outside YouTube; SoundCloud and Bandcamp songs play in the app only.
